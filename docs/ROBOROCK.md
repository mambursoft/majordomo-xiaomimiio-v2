# Roborock через модуль Xiaomi MiIO (тільки PHP)

Модуль працює напряму з пристроєм по протоколу miIO (UDP, порт 54321). Python-скрипти не використовуються.

## 1. Отримання токена без Python

1. У Mi Home / Xiaomi Home зробіть резервну копію даних.
2. У розпакованій копії знайдіть файл `backup_info` і поле `token` для пилососа (32 hex-символи).
3. IP пристрою можна побачити в панелі роутера.
4. У MajorDoMo: `Xiaomi miIO -> Devices`, виберіть тип `roborock.vacuum.*`, вставте IP і токен.

Токен чутливий — не публікуйте його в логах і скріншотах.

## 2. Мапа

Кнопка **Roborock vacuum** відкриває сторінку. **Load map** виконує `get_map_v1`, розпаковує RR-файл, розбирає блоки й малює PNG через GD: сіре — кімнати, темне — стіни, синє — шлях, червоне — робот, зелене — база, оранжеве — зони. Файл: `cms/cached/xiaomimiio/vacuum-<ID>.png`.

## 3. Координати

Координати в міліметрах; піксель = координата / 50. Зона: `x1,y1,x2,y2,проходи` (1..3), наприклад `26234,26042,27284,26642,1`.

## 4. Кімнати

**Load rooms** виконує `get_room_mapping` і показує кнопки сегментів. Натискання надсилає `app_segment_clean` з номером сегмента.

## 5. Команди

`app_start`, `app_pause`, `app_stop`, `app_charge`, `app_spot`, `app_zoned_clean`, `app_goto_target`. Після команди мапа оновлюється автоматично.

## 6. Діагностика

- `Map decode failed` — модель не підтримує `get_map_v1` або хибний токен;
- порожній список кімнат — немає `get_room_mapping`;
- помилка авторизації — перевірте IP і токен.
